                                                                                                                                                                                                                                                                                                                                                                          # Data

This project uses quarterly tourism trip data for Melbourne, Victoria, Australia, from the Australian domestic tourism dataset, filtered to two travel purposes:

- **Business** trips (`y1`) — 80 quarterly observations, 1998 Q1 to 2017 Q4
- **Holiday** trips (`y2`) — 80 quarterly observations, 1998 Q1 to 2017 Q4

The source file is expected at `data/tourism_Project.csv` with at least the columns `Purpose` and `Trips`. It is not committed to this repository — place your own copy at that path before running the scripts.

The original Australian domestic tourism dataset (from which this Melbourne/Victoria subset is drawn) is commonly distributed via the `tsibbledata::tourism` R package, used widely in forecasting coursework (e.g., Hyndman & Athanasopoulos, *Forecasting: Principles and Practice*).
